# RoylTEE

A permissioned registry of music rights shares on NEAR testnet: each share is an NFT that controls its own keyless payout vault. The full judge-facing README lands in block 7; until then see DESIGN.md and THREAT_MODEL.md. Testnet only, mock USDC only.

The website, with the help chat and wallet support tickets, is in `site/` (see `site/README.md`).
